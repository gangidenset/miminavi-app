# ミミナビ（Android 最小版）

「耳だけで、迷わないスマートナビゲーション」の最小ゴール版です。

- Android アプリとして起動する
- iPhone の Beacon Simulator が送る iBeacon を受信する
- 事業所の図面（約60m²）を持ち、図面上に置いた iPhone から現在地を推定する
- 行き先（会議室(8)/(4)/(2)・事務所）を声か文字で伝えると、ルートを計算して音声で案内する

画面のデザインはデモ（ミミナビ.html）に合わせています。

## 構成

| 場所 | 内容 |
|---|---|
| `app/src/main/java/jp/miminavi/app/MainActivity.java` | 画面（WebView）と端末機能の窓口。権限、読み上げ、音声認識、方位センサー |
| `app/src/main/java/jp/miminavi/app/BeaconScanner.java` | BLE スキャン。RSSI を直近4秒で平均し、0.5秒ごとに画面へ渡す |
| `app/src/main/java/jp/miminavi/app/BeaconParser.java` | 広告パケットの解析（iBeacon / AltBeacon / Eddystone-UID） |
| `app/src/main/assets/index.html` `app.css` `app.js` | 画面・図面・位置推定・ルート探索・案内 |

外部ライブラリは使っていません（Android Gradle Plugin 9.4.1 / Gradle 9.6.0 / Java のみ）。

## 動かし方

1. Android Studio で「Open」からこのフォルダ（MimiNavi）を開く
2. Gradle の同期が終わったら、USB デバッグを有効にした Android 端末をつなぎ、▶（Run 'app'）を押す
   - SDK Platform 36 が入っていない場合は、Android Studio の案内に従ってインストールしてください
3. 初回起動時に「付近のデバイス」と「位置情報」の許可を求められるので、両方許可する
4. 端末の位置情報（設定のクイックパネル）もオンにする。オフだとビーコンが見えない機種があります

`index.html` は PC のブラウザでも開けます。その場合は疑似ビーコン4台で画面の動きを確認できます。

## iPhone（Beacon Simulator）の設定

- 形式：iBeacon
- UUID：全台同じ値（例：E2C56DB5-DFFB-48D2-B060-D0F5A71096E0）
- Major：全台 1
- Minor：台ごとに 1, 2, 3 …
- iPhone は画面をつけたまま、アプリを前面に表示しておく（画面が消えると送信が止まります）

## 使い方

1. 「ビーコン」タブに受信中の iPhone が一覧で出ます（Major / Minor、RSSI、推定距離）
2. 一覧の「図面に配置」→ 図面上で iPhone を置いた場所をタップ。B-01, B-02 … の名前で登録されます
   - 点線の丸は、デモで想定していた設置位置（入口・事務所前・廊下・各会議室）です
3. 「図面」タブで、推定した現在地（オレンジの点）と各ビーコンまでの推定距離（円）を確認できます
4. 「案内」タブ →「この施設で案内を始める」→ 方角合わせ → 行き先を話す
   - 現在地が分かっていれば、そこからのルートで案内し、歩くとビーコンの受信状況に合わせて進みます
   - 目的地に置いたビーコンの約1m以内に近づくと「到着しました」と読み上げます
   - 現在地が分からないときや「デモ歩行」を押したときは、デモと同じように自動で歩く想定で進みます

## 位置推定のしくみ（PoC 用の簡易版）

- 距離 = 10^((1m地点のRSSI − 受信RSSI) ÷ (10 × n))。n は「ビーコン」タブで調整（初期値 2.0）
- 1m地点のRSSI は iBeacon の送信値（未設定なら −59dBm）。「1mで補正」でその場の値に置き換えられます
- 近い順に最大4台を、距離の2乗の逆数で重み付けして平均し、前回の位置となめらかにつなぎます
- 推定位置は歩ける場所（図面の通路・部屋）のいちばん近いマスに寄せてからルートに当てはめます

## 図面について

- 1マス = 0.6m、外壁の内側が 14×12 マス（8.4m × 7.2m ≒ 60m²）
- 間取りはデモの「事業所」をそのまま使っています。実際の図面に合わせるときは `app.js` の `OFFICE.grid`（`#` が壁、`.` が歩ける場所）、`rooms`、`dests` を書き換えてください

## 既知の制約

- 案内中はアプリを前面に表示したまま使う前提です（画面消灯中のスキャンは未対応）
- 音声認識は端末の音声入力（Google など）を呼び出します。入っていない端末では文字入力を使ってください
- 読み上げは端末の日本語音声を使います
